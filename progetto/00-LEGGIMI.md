# Progetto WebXR

Progetto unico per tutte le app XR (realtà virtuale/aumentata nel browser) che realizziamo, per il visore Pico 4 della scuola e altri dispositivi.

Cartella del progetto: `C:\Users\Samsung\webXR`
Ogni app sta in una sua sottocartella accanto a `progetto` (la prima è `scienze-vr`).

## Come iniziare
1. Apri Claude Code nella cartella `C:\Users\Samsung\webXR`.
2. Scrivi: "Leggi i file in progetto/ e fai il Prossimo passo".
3. Claude presenta il piano e aspetta il mio ok prima di scrivere codice.

## File in questa cartella
- `00-LEGGIMI.md`: questo file.
- `01-regole-comuni.md`: regole tecniche e modo di lavorare, valide per tutte le app.
- `02-elenco-app.md`: le app, con obiettivo e moduli di ciascuna.
- `03-prossimo-passo.md`: cosa fare adesso. Si aggiorna a ogni fase.
